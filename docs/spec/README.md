# TLA+ 명세

동시 실행이 걸린 흐름(정원, 대기 순번, refresh 토큰 교체, 멱등 처리)의 수학적 모델을 둔다.

## 규칙

- 파일 하나에 흐름 하나: `<흐름>.tla` + 검사 설정 `<흐름>.cfg`
- 불변식 이름은 `docs/invariants/INVARIANTS.md`의 ID와 맞춘다. 예: `INV_AUTH_001 == ...`
- 검사 범위(사용자 수, 요청 수 등)는 `.cfg`에 적고, 왜 그 범위면 충분한지 명세 상단 주석에 남긴다.
- 명세를 바꾸면 TLC 검사를 다시 돌리고, 같은 시나리오의 동시성 통합 테스트(L5)도 함께 갱신한다.

## 실행

`scripts/tlc-check.sh` (Gradle 프로젝트 생성 시 함께 추가 예정)
