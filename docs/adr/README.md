# 기술 결정 기록 (ADR)

이 프로젝트에서 내린 중요한 기술 결정과 그 이유를 기록합니다.
결정을 바꿀 때는 기존 문서를 지우지 않고, 새 ADR을 추가한 뒤 기존 문서의 상태를 "대체됨"으로 바꿉니다.

## 상태

- 제안: 초안. 검토 후 확정 예정
- 확정: 이 결정대로 구현
- 대체됨: 다른 ADR로 바뀜

## 작성 형식

각 문서는 아래 순서를 따릅니다.

1. 상태와 날짜
2. 맥락: 왜 이 결정이 필요한가
3. 선택지: 검토한 대안
4. 결정: 무엇을 골랐나
5. 결과: 얻는 것과 감수하는 것
6. 다시 볼 조건: 어떤 상황이 오면 재검토하나
